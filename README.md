# iihmsp2026

It is our greatest pleasure to welcome you to the 22nd International Conference on Intelligent Information Hiding and Multimedia Signal Processing (IIHMSP 2026), hosted by Yango University, Fuzhou, China. The conference will be held from October 23, 2026 to October 26, 2026 at the Yango University, Fuzhou, China.
Multimedia technologies facilitate the creation of global information infrastructure for acquiring, storing, and communicating data in different forms. The proliferation of multimedia applications raises challenges such as multimedia security and privacy, big data in multimedia, and ntelligence in multimedia processing.
